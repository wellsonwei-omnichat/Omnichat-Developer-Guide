# Overview

The Conversion API can help you track customers' behavior on Web / Mobile App by sending the events directly from your systems to Omnichat.

Currently, this API supports the following event types:

- Pageview
- View product
- Add to cart
- Remove from cart
- Checkout
- Purchase
- Traffic Source
- Member Mapping
