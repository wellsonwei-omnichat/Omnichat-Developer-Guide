**Bearer** HTTP Authentication is used for Omnichat Open API, you will be given an API Token from Omnichat.

Sending HTTP requests with the Authorization header that contains the word **Bearer** followed by a space and an API Token

| Security Scheme Type | HTTP Authorization Scheme |
| :------------------- | :------------------------ |
| HTTP                 | Bearer                    |
