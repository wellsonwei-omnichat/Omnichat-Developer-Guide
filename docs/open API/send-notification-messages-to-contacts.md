# Subscription Required

Marketing Cloud / Social CDP Cloud

Notification Open API Module

# Request

## Endpoint

**POST** <https://open-api.omnichat.ai/v1/notification-messages>

## Request Body

| Field         | Type                         | Required | Description             |
| :------------ | :--------------------------- | :------- | :---------------------- |
| notifications | Array of Notification Object | Y        | Available size: 1 ~ 100 |

# Response

## Response Body

### Success

| Field     | Type   | Nullable | Description                                             |
| :-------- | :----- | :------- | :------------------------------------------------------ |
| triggerId | String | N        | A random string generated by Omnichat for each API call |

### Success Example

```json
{
  "triggerId": "65eeb7e89282985332c3a3df" 
}
```

### Failed

The notification service is asynchronized, so each error isn't returned immediately.
